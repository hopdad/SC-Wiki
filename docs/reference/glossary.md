# Glossary

Supply chain and systems terminology used across Meijer.

| Term | Definition |
|---|---|
| **ASN** | Advance Ship Notice — EDI 856 document notifying receiver of incoming shipment details |
| **BOL** | Bill of Lading — shipping document between carrier and shipper |
| **Cross-dock** | Receiving product and shipping it out without putting it into storage |
| **DC** | Distribution Center — warehouse facility for receiving, storing, and shipping products |
| **DSD** | Direct Store Delivery — supplier delivers directly to store, bypassing DC |
| **EDI** | Electronic Data Interchange — standardized electronic business document exchange |
| **FEFO** | First Expired, First Out — inventory rotation based on expiration date |
| **FIFO** | First In, First Out — inventory rotation based on receipt date |
| **GS1** | Global Standards Organization — manages barcodes, GTIN, and supply chain standards |
| **GTIN** | Global Trade Item Number — unique product identifier (UPC/EAN) |
| **LPN** | License Plate Number — unique identifier for a container/pallet in the warehouse |
| **MOQ** | Minimum Order Quantity — smallest amount a supplier will accept |
| **PO** | Purchase Order — document authorizing a purchase from a supplier |
| **RF** | Radio Frequency — handheld scanning devices used in warehouse operations |
| **SKU** | Stock Keeping Unit — unique identifier for a product variant |
| **SLA** | Service Level Agreement — performance standards between parties |
| **Slotting** | Assigning optimal storage locations to products in the warehouse |
| **VAN** | Value-Added Network — intermediary network for transmitting EDI documents |
| **Wave** | A group of orders released together for picking in the warehouse |
| **WMS** | Warehouse Management System — software managing warehouse operations |
| **TMS** | Transportation Management System — software managing transportation |

*This glossary will grow as content is added. Contribute terms via pull request.*
